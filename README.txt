TRACKER — публикация через GitHub Pages

1. Создайте публичный репозиторий.
2. Загрузите ВСЕ файлы и папки из этого архива в корень репозитория.
3. Settings → Pages → Build and deployment → Deploy from a branch.
4. Branch: main; Folder: /(root); Save.
5. Дождитесь публикации и откройте ссылку вида https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/

Примечание: GitHub Pages публикует содержимое репозитория публично. Не размещайте здесь резервные копии пользовательских данных.
